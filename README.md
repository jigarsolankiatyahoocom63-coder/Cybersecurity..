# CyberSafe – Password Hygiene and Personal Data Protection Campaign

CyberSafe is a community-oriented cybersecurity awareness website designed for the Community Engagement Programme (CEP). It teaches ordinary internet users how to protect passwords, personal data, online transactions, and digital identity with clear, practical steps.

## Run the site
- Open index.html directly in a browser, or
- Run a simple static server in the project folder and open the local URL.

Example:

python -m http.server 8000

Then open http://localhost:8000

## Stack constraints
- HTML5
- CSS3
- Vanilla JavaScript (ES6 modules)
- No external libraries or CDNs
- No backend required for local demo use

## Folder structure
- index.html – homepage
- pages/ – all module and feature pages
- css/ – base, layout, components, themes, print styles
- js/ – modules for pages, components, services, entities, config, utilities
- assets/ – icons, images, printable resources
- docs/ – planning and testing files

## Optional sign-up note
The sign-up form uses browser-only PBKDF2 hashing with a salt and is a demonstration-level account system. It is not intended for production security.

## Privacy note
Public statistics are aggregated and anonymised. This site stores data locally in the browser and is designed for local demonstration and facilitator use.

## Project goals
- Teach password hygiene and safer digital habits
- Highlight phishing, scams, malware, and risky online behaviour
- Support pre/post awareness assessment and community learning
- Provide printable resources and facilitator-friendly tools
