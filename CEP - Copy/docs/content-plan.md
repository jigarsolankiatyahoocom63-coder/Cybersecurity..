# CyberSafe Content Plan

## Awareness areas
1. Password Hygiene
2. Personal Data Protection
3. Online Threats
4. Campaign & Awareness

## Module map
1. Introduction to Password Hygiene
2. Creating Strong Passwords
3. Password Management
4. Two-Factor Authentication (2FA)
5. Personal Data Protection
6. Online Privacy
7. Social-Media Safety
8. Safe Online Transactions
9. Phishing and Social Engineering
10. Malware and Suspicious Downloads
11. Common Cyber Scams
12. What to Do After an Account or Data Compromise
13. Cybersecurity Quiz
14. Password-Strength Checker
15. Personal-Data Protection Checklist
16. Campaign Resources

## Content structure for each module
- Why this matters
- What ordinary users should know
- Everyday examples and common mistakes
- "Do" and "Don't" guidance
- Scenario or mini-check challenge
- Key takeaways
- Resource links and related modules

## Learning flow for facilitators
- Start with the password and data-protection basics.
- Move into threat recognition and scam awareness.
- Use the quiz as a baseline before the workshop.
- Use tools for checklists and password analysis.
- Finish with resource handouts, campaign summary, and action steps.

## Communication style
- Plain language and everyday examples
- No technical jargon unless explained simply
- Action-oriented, not shame-based
- Emphasis on practical daily habits
